# 🛠 Maintenance Guide

## Quick Reference — Where to Change Things

| What you want to change | File | Location |
|---|---|---|
| Add / remove a key | `index.html` | `const KEYS = [...]` |
| Add / remove a touch method | `index.html` | `const TOUCHES = [...]` |
| Add / remove a tempo | `index.html` | `const TEMPOS = [...]` |
| Change colors / fonts | `index.html` | `:root { }` in `<style>` |
| Change page title | `index.html` | `<title>` and `<h1>` |

## How to Edit

### Add a new touch method
Open `index.html`, find `const TOUCHES = [`, add a new line inside the array:
```javascript
"Your new method here",
```

### Add a new key
Open `index.html`, find `const KEYS = [`, add inside the array:
```javascript
"C-sharp major",
```

### Add a new tempo
Open `index.html`, find `const TEMPOS = [`, add a number:
```javascript
const TEMPOS = [80, 90, 100, 120];
```

## How It Was Built

### Stack
- Pure HTML + CSS + JavaScript — no framework, no build step
- Google Fonts: Playfair Display, DM Mono, DM Sans
- Data stored in browser `localStorage` (today's history only, clears at midnight)

### Creation steps
1. Designed and generated by Claude (claude.ai) as a single `index.html` file
2. Renamed to `index.html`
3. Created GitHub repo: `piano-scale-lottery` under account `chelsietao`
   - Visibility: Public
   - License: MIT
   - README: enabled
4. Uploaded `index.html` via **Add file → Upload files**
5. Enabled GitHub Pages: **Settings → Pages → Deploy from a branch → main → Save**
6. Live at: `https://chelsietao.github.io/piano-scale-lottery/`

## How to Update the Site

1. Edit `index.html` locally (or directly on GitHub)
2. On GitHub: click `index.html` → pencil icon → paste updated content → **Commit changes**
3. Site updates automatically within 1–2 minutes

## Notes

- Each draw result can be applied to both **scales** and **arpeggios** in the same key
- History is stored in the browser only — it does not sync across devices
- No server, no database, no dependencies to update
