# 🎹 Piano Scale Practice Lottery

A simple tool to eliminate decision fatigue before piano practice.
Spin the wheel and just play what you get.

## What it does

Randomly draws a combination of:
- **Key** — all 24 major and minor keys
- **Touch / Articulation** — 38 technique options
- **Tempo** — 80 / 90 / 100 BPM

Draw 1, 3, or 5 sets at a time. Today's history is saved automatically.

## How to use

👉 [Open the Lottery](https://chelsietao.github.io/piano-scale-lottery/)

Open it before practice, draw a set, and follow what you get.
No thinking required.

## What to practice with each draw

Each result can be applied to both:
- **Scales** — Ascending → contrary motion → descending, 4/4 time
- **Arpeggios** — Same key, same touch, same tempo. Root position and inversions.

Use the same articulation and tempo for both — it makes for a complete, focused mini-session.

## Range

- 24 keys (all major and minor)
- 38 touch and articulation options
- Tempo: 80 / 90 / 100 BPM

## About

A personal practice tool built to solve one problem:
not knowing what to practice when you sit down at the piano.
